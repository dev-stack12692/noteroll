Shuru karne se pehle

PDF limit 3 MB per file hai. Teacher ke notes/PDFs 14 din baad expire hote hain. PDF par personal pen/highlight marks sirf us browser mein save hote hain. Zaroori copy time par download/export karo.

For teachers

Class notes share kaise karein

  1. Teacher account banao

    Teacher sign in kholo. Pehli baar New account chuno, naam, email aur password bharo, phir Create account. Pehle se account hai toh Sign in karo. Password kam se kam 8 characters ka rakho.

  2. Apni class set up karo

    Set up your class mein class/centre ka naam likho. Batches comma se alag karo, jaise Class 8, Class 9. UPI details optional hain; notes share karne ke liye payment setup zaroori nahi. Create centre tap karo.

  3. Student add karo aur uska code lo

    Students → Add student. Student name aur sahi Batch bharo, phir Save. Us student ka edit button kholo: yahan 8-letter Join code milega. Ye code sirf usi student ko do. Ye har student ka alag code hai, ek common batch code nahi.

  4. PDF upload karo

    Notes → Upload PDF. Title likho, Who can read it mein sahi batch ya All batches chuno, PDF select karo aur Upload tap karo. PDF 3 MB ya usse chhota ho. Upload complete hone par file list mein dikhegi.

  5. Ya seedha text note likho

    New note chuno. Title, batch aur note ka text bharo. Publish karo. Ye teacher ka class note hai, student ke private My notes se alag.

  6. Student ki request approve karo

    Student apna account banakar code enter karega. Students mein Student requests dekho, naam aur sahi student record milao, phir Approve. Unknown ya galat request ko approve mat karo. Student ko page reload karke dobara dekhne bolo.

Galat file ya galat student?

Notes list ka delete button poori class ke liye file hata deta hai. Student ka Delete everything uske attendance, fees aur results bhi hata sakta hai. Sirf access check karne ke liye delete mat karo; irreversible confirmation dhyan se padho.

For students

Apne teacher ke notes kaise padhein

  1. Student account banao

    Student sign in kholo. New account se apna naam, email aur password bharo. Student account chuno, Teacher nahi. Account hai toh Sign in karo.

  2. Teacher ka code enter karo

    Join your teacher's batch mein teacher ka diya 8-letter code aur apna naam likho. Send request tap karo. Code nahi hai toh teacher se apne student record ka code maango.

  3. Approval ka wait karo

    Waiting for the teacher ka matlab request abhi approve nahi hui. Teacher se approve karwao, phir page reload karo. Sirf code bharne se material nahi khulta.

  4. Notes and PDFs se file kholo

    Approval ke baad class card ke andar Notes and PDFs dekho. File ke saamne Open tap karo. Sirf tumhare batch ya All batches ke liye share hua material dikhega.

  5. Read, mark aur apni copy export karo

    PDF reader ke tools neeche samjhaye hain. Original file rakhni hai toh Download original. Apne pen/highlight ke saath chahiye toh Export marked PDF.

Inside a PDF

Reader ke tools

PDF khulne par pehli baar reader load hone mein thoda waqt lag sakta hai. Page render hone tak wait karo.

Read

Page ko normal scroll karke padho. Mark lagane ke baad scroll karna ho toh Read par wapas aao.

Previous / Next

PDF ka pichhla ya agla page kholo. Beech mein current page / total pages dikhta hai.

Zoom

Fit width, 150% ya 200% chuno. Zoomed page mein horizontal scroll ki zaroorat ho sakti hai.

Pen / Highlight

Tool select karo aur ungli, stylus ya mouse se page par drag karo. Ink se colour badal sakte ho.

Text

Text chuno, page par jagah tap karo aur text likho. Ek text mark mein 160 characters tak.

Eraser

Apne mark ke paas tap karke use hatao. Ye original PDF ka content erase nahi karta.

Undo / Redo

Current reader session ka last mark change wapas lo ya phir se lagao.

Export marked PDF

Apne marks ke saath PDF download karo. Download original teacher ki unmarked file deta hai.

Marks aur account notes ek cheez nahi hain

PDF marks browser-local hain. Doosre phone/browser mein login karne se ye marks nahi aayenge. Browser data clear karne se marks kho sakte hain. Apna marked PDF export karke rakho.

Your own writing

My notes kaise use karein

  1. Apna note likho

    Student home par My notes → New note. Title aur text bharo, phir Save to my account. Ye text notes account mein save hote hain; PDF marks ki tarah browser-only nahi.

  2. Edit ya download karo

    Note ka Open tap karo. Edit se badlo ya Download se text file lo. Zaroori notes ka backup rakho.

  3. Share karna optional hai

    Agar Share this note with my teacher dikhe, tick karne par teacher padh sakta hai. Off rakho toh private to your account. Shared copy teacher ke Notes shared by students mein aati hai. Save ke baad sharing-error message aaye toh dobara check karo.

My notes mein 100 text notes tak rakh sakte ho. Ye handbook current main app ke liye hai, Classic notebook ke purane flow ke liye nahi.

Optional

Baaki class tools kahan hain?

Notes primary hain. Teacher ke liye Class admin aur More mein attendance, fees, test results, homework, online exams aur settings milte hain. Desktop par sidebar mein direct links bhi hain.

  • Students: student add/edit, batch aur join requests.
  • Attendance / Fees: teacher ki class records. Notes padhne ke liye UPI payment setup zaroori nahi.
  • Homework / Results / Exams: teacher jo publish karega, student ko apni class ke andar dikhega.
  • Fees: UPI payment teacher ko seedha jata hai. I have paid sirf teacher ko claim batata hai, payment proof nahi; teacher verify karta hai.
Keep your work safe

Save, expiry aur privacy

  • Class notes/PDFs 14 din baad expire. Students se hide ho jate hain; expired material baad mein app khulne par erase hota hai. Expiry se pehle original ya marked copy download karo.
  • PDF marks sirf isi browser mein. Auto-save status dekho. Storage-full error aaye toh close karne se pehle export karo. Browser-local saving ko cloud backup mat samjho.
  • My notes account mein. Student ke text notes alag hain. Shared flag aur teacher-sharing choice dhyan se chuno.
  • Main-app PDFs end-to-end encrypted nahi. Sensitive personal documents upload mat karo. Student access teacher approval aur batch se controlled hai.
  • AI abhi enabled nahi hai. Is main-app reader mein AI answer/explain feature ka button ya guarantee nahi hai.
  • Free service ki limits hain. Heavy use ya connection problem se loading ruk sakti hai. Apni zaroori copy ka backup rakho.

When something gets stuck

Problems & fixes

Code nahi mil raha ya “code not found” aa raha hai

Teacher Students mein tumhara edit button kholkar Join code de. 8 letters dhyan se copy karo. Naya code banne par purana code kaam nahi karega. Student account se hi request bhejo.

Approval ke baad bhi Waiting for the teacher dikh raha hai

Teacher se confirm karo ki sahi request approve hui hai. Phir page reload karo ya sign out karke same student email se sign in karo. Baar-baar naye accounts mat banao.

Notes list khaali hai

Teacher ne sahi batch ya All batches chuna hai? Student ke record ka Batch sahi hai? Material 14 din se purana toh nahi? Teacher se in cheezon ko check karwao.

Upload nahi ho raha

Sirf PDF file chuno, 3 MB ya usse chhoti. Badi PDF compress/split karke upload karo. Internet check karo aur Uploaded confirmation/list mein item aane tak wait karo.

PDF load hone mein time lag raha hai

Pehli baar PDF reader libraries load hoti hain. Internet stable rakho aur thoda wait karo. Agar error aaye toh Download original se file rakh sakte ho; baad mein app reload karke dobara kholo.

Doosre phone mein pen/highlight nahi dikh rahe

Ye expected hai: PDF marks browser-local hain. Pehle device par Export marked PDF karo aur exported file doosre device par kholo. Sirf login se PDF marks sync nahi hote.

Scroll karte waqt pen chal raha hai

Toolbar mein Read select karo. Pen/Highlight mode touch ko drawing ke liye use karta hai.

Password bhool gaye

Sign in page par email likho aur Forgot password tap karo. Same account ka reset email check karo, spam folder bhi. Kisi ko password ya reset link share mat karo.
